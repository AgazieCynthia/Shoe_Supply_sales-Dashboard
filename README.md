# Shoe Supply Sales Dashboard

## Project Overview
This project analyzes sales performance for a shoe supply business using Power BI. The dashboard provides interactive insights into revenue, Units sold, sales trends, product performance, and sales channels to support data driven decision making.

## Business Problem
The objective was to transform raw sales data into an interactive dashboard that enables users to monitor business performance and identify key sales trends.

## Tools Used
- Microsoft Excel
- Power BI

## Skills Demonstrated
- Data Cleaning
- Data Validation
- Dashboard Development
- Data Visualization
- KPI Reporting
- Business Analysis

## Dashboard Features
- Total Revenue
- Total Units Sold
- Qty sold by Country
- Revenue by Brand
- Revenue by Sales Channel
- Trend of sales across the months
- Interactive Filters and Slicers
